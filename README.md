## Forensic research standard

The investigation records in this repository separate verified on-chain facts from strong correlations, leads, and unproven attribution. Code reuse, funding paths, explorer labels, naming similarities, and metadata patterns are documented as evidence rather than proof.

Evidence status legend:
- Verified — On-chain fact confirmed by direct contract state or cryptographic proof
- Correlated — Strong pattern match, naming/code similarity, funding path alignment
- Investigating — Lead documented, proof pending or in progress
- Hypothesis — Theory without verification; requires next-step proof
- Blocked — Verification blocked awaiting external data, chain state, or decision
